# Documentation for `stat_matcher.py`

# Technical Documentation for the Python Script

## Overview

This Python script is designed to facilitate semantic matching of statistical data using embeddings generated by the SentenceTransformer library. The script provides tools for creating, saving, loading, and querying indices of statistical mappings. It includes command-line interface (CLI) commands to streamline the creation of these indices, run tests, and perform queries. The key functionalities are built around matching statistics for sports entities using pre-trained language models to find semantic similarities between descriptions and queries.

## Dependencies

- **numpy**: Used for numerical operations, particularly for handling array operations.
- **sentence_transformers**: Provides the `SentenceTransformer` model to encode text into embeddings.
- **pickle**: Used for serializing and deserializing Python objects, allowing for saving and loading of computed indices.
- **enum**: Utilized for defining enumeration classes to handle different model choices.
- **json**: Used for parsing and generating JSON formatted data.
- **typer**: A library for building command-line interfaces.
- **os**: Provides a way of using operating system-dependent functionality like directory and file path manipulation.
- **re**: Used for regular expression operations, assisting in text parsing and query processing.
- **time**: Used for measuring the time taken by operations, useful for performance evaluation.

## Classes and Functions

### `STModelChoice` Enum

- **Purpose**: Defines the available SentenceTransformer models for encoding text.
- **Attributes**:
  - `MINILM_L6_V2`: Represents the "all-MiniLM-L6-v2" model, a lightweight and efficient model for generating sentence embeddings.

### `StatIndex` Class

- **Purpose**: Manages the creation, saving, loading, and encoding of statistical mappings into embeddings.
- **Attributes**:
  - `stat_mapping_file`: Path to the JSON file with statistical mappings.
  - `encoding_model`: The model used for encoding, defaulting to `MINILM_L6_V2`.
  - `stat2ind`: Dictionary mapping statistics names to their indices.
  - `ind2stat`: List mapping indices back to statistic names.
  - `corpus_embeddings`: List of precomputed embeddings for the statistical corpus.
  - `model`: Instance of the SentenceTransformer model.

#### Methods

- `__init__`: Initializes the class with a mapping file and an encoding model.
- `create`: Generates embeddings for the statistics, creating the index.
- `save`: Serializes and saves the index to a specified path.
- `load`: Deserializes an index from a file, reconstructing the embeddings and mappings.

### `StatMatcher` Class

- **Purpose**: Matches queries to statistical indices, utilizing the embeddings for semantic similarity.
- **Attributes**:
  - `index`: Instance of `StatIndex` used for querying.
  - `condition_splitter`: Regular expression pattern for splitting query conditions.

#### Methods

- `__init__`: Initializes with a `StatIndex` instance.
- `from_sport_and_entity`: Static method to create a `StatMatcher` for specific sport and entity combinations.
- `get_all_stat_matchers`: Static method to generate `StatMatcher` instances for all available sport and entity combinations.
- `match`: Matches a query against the indexed statistics, returning the top-k matches based on similarity.

### `test_stat_matching_with_sample` Function

- **Purpose**: Tests the matching process by processing sample queries, compares results against known matches, and evaluates performance.
- **Parameters**:
  - `stat_mapping_file`: Path to the statistical mapping JSON file.
  - `test_file`: Path to the test queries JSON file.
  - `output_file`: Path to save the test results.
  - `top_k`: Number of top matches to consider (default is 10).

### CLI Commands

Implemented using `typer`, providing a user-friendly interface for interacting with the script.

- `create_index`: Creates and saves a new statistical index.
  - Arguments: `stat_mapping_file`, `save_path`.
- `test`: Runs statistical matching tests.
  - Arguments: `stat_mapping_file`, `test_file`, `output_file`, `top_k`.
- `query`: Performs a single query against a statistical index.
  - Arguments: `index_file`, `query`, `top_k`.

## Important Details

- **Directory Structure**: The script assumes a specific directory structure for storing model assets and indices. Paths are dynamically constructed using the `os` module.
- **Model Loading**: The script dynamically loads SentenceTransformer models, ensuring compatibility with saved indices.
- **Performance Measurement**: The script includes time measurements for operations, providing insights into performance and optimization opportunities.

This documentation provides a comprehensive understanding of the script's functionality, aiding developers and users in effectively utilizing the provided tools for semantic matching of statistical data.
